# portscan

Go-пакет для проверки доступности TCP-портов на одном или нескольких хостах.
Обычный TCP connect, без SYN-сканирования, UDP и raw-сокетов, поэтому root не
нужен. Только стандартная библиотека, сторонних зависимостей нет.

```bash
go get github.com/MosinEvgeny/portscan
```

Нужен Go 1.25.5.

## Быстрый старт

```go
scanner, err := portscan.New(
	portscan.WithConcurrency(100),
	portscan.WithConnectTimeout(500*time.Millisecond),
)
if err != nil {
	log.Fatal(err)
}

ctx, cancel := context.WithTimeout(context.Background(), time.Minute)
defer cancel()

ports := portscan.Union(portscan.Ports(22, 443), portscan.Range(8000, 8100))
results, err := scanner.Scan(ctx, []string{"192.168.1.10", "example.com", "::1"}, ports)
if err != nil {
	log.Fatal(err) // скан не начался: плохой ввод или ctx уже отменён
}

for r := range results {
	if errors.Is(r.Err, portscan.ErrUnresolvable) {
		fmt.Printf("%s: имя не разрешилось\n", r.Host)
		continue
	}
	if r.State == portscan.StateOpen {
		fmt.Printf("%s (%s):%d открыт за %v\n", r.Host, r.IP, r.Port, r.Duration)
	}
}
if ctx.Err() != nil {
	fmt.Println("скан мог быть прерван, результаты могут быть неполными")
}
```

Примеры лежат в `example_test.go`.

## Публичный API

| Что                                                                        | Назначение                                              |
|----------------------------------------------------------------------------|---------------------------------------------------------|
| `New(opts ...Option) (*Scanner, error)`                                    | создаёт сканер                                          |
| `WithConcurrency(n)`                                                       | сколько подключений идёт одновременно, по умолчанию 100 |
| `WithConnectTimeout(d)`                                                    | сколько ждать один порт, по умолчанию 1 с               |
| `WithResolver(r)`, `WithDialer(d)`                                         | подмена DNS и подключения (для тестов и своих сетей)    |
| `(*Scanner).Scan(ctx, hosts, ports)`                                       | запускает скан, возвращает `<-chan Result`              |
| `Ports(...)`, `Range(a, b)`, `Union(...)`, `ParsePorts("22,80,8000-8100")` | собирают `PortSet`                                      |
| `Result`, `State`                                                          | итог проверки одного порта                              |
| `Err*`                                                                     | ошибки, которые проверяются через `errors.Is`           |
| `Resolver`, `Dialer`                                                       | интерфейсы под `*net.Resolver` и `*net.Dialer`          |

Больше ничего не экспортируется. Полное описание: `go doc -all`.

### Как это устроено

- **Опции функциями.** `New` принимает `Option`, значения по умолчанию рабочие,
  неверная опция (`WithConcurrency(0)`, `nil`-резолвер) даёт `ErrInvalidOption`.
  Если неверны сразу несколько, в ошибке будут все.
- **`Scanner` неизменяем.** После `New` его настройки не меняются, поэтому один
  экземпляр можно использовать из нескольких горутин и для нескольких `Scan`.
- **`PortSet` неизменяем.** Внутри отсортированные слитые диапазоны: набор
  `1-65535` занимает одну запись, а не 65 тысяч. Конструкторы не возвращают
  ошибку, чтобы их можно было вкладывать друг в друга (`Union(Ports(...), Range(...))`).
  Ошибка запоминается в наборе и выходит из `Err()` и из `Scan`.
- **Две категории ошибок.** `Scan` возвращает `error` только если скан нельзя
  начать (плохой хост, плохие порты, `ctx` уже отменён). Всё, что случилось во
  время скана, приходит в `Result`. Так читатель канала обрабатывает один поток,
  а не два.
- **Состояние порта задаёт `State`, а не текст ошибки.** `Result.Err` хранит
  исходную ошибку для логов и `errors.Is`, но решение принимается не по ней.

## Хосты

`hosts` может содержать IPv4, IPv6 и DNS-имена. CIDR не поддерживается.

| Ввод                                                     | Что происходит                                                                                                                                                                                                       |
|----------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| пустой список                                            | `Scan` возвращает `ErrNoTargets`                                                                                                                                                                                     |
| `""` или одни пробелы                                    | `ErrEmptyHost`                                                                                                                                                                                                       |
| не IP и не имя (`"a b"`, `"10.0.0.0/24"`, `"999.1.1.1"`) | `ErrInvalidHost`                                                                                                                                                                                                     |
| один плохой хост среди хороших                           | `Scan` возвращает ошибку и ничего не сканирует; в ошибке перечислены все плохие хосты                                                                                                                                |
| дубли                                                    | убираются: `1.2.3.4` и `::ffff:1.2.3.4` один хост, имена сравниваются без учёта регистра и без точки в конце; в `Result.Host` остаётся первое написание                                                              |
| имя с несколькими IP                                     | сканируются все адреса, в `Result.Host` имя, в `Result.IP` конкретный адрес                                                                                                                                          |
| разные имена с одним IP                                  | адрес проверяется один раз, за тем именем, что стояло раньше                                                                                                                                                         |
| имя не разрешилось                                       | остальные хосты сканируются, по этому приходит один `Result` с `Port == 0`, пустым `IP`, `State == StateError` и `Err`, которая оборачивает `ErrUnresolvable` (и исходную ошибку DNS). Такие результаты идут первыми |

Имена проверяются по RFC 1123 (плюс `_`). Не-ASCII имена нужно передавать
в punycode (`xn--...`).

## Порты

| Ввод                                      | Что происходит                                 |
|-------------------------------------------|------------------------------------------------|
| порт `0`, больше `65535`, не число        | `ErrInvalidPort`                               |
| обратный диапазон `Range(1000, 1)`        | `ErrInvalidRange`, границы местами не меняются |
| пустой набор, `Ports()`, `ParsePorts("")` | `ErrNoPorts`                                   |
| дубли и пересечения                       | сливаются, порт проверяется один раз           |
| `Union` с ошибочным набором               | ошибка сохраняется в результате                |

`ParsePorts` понимает записи вида `"22, 80, 8000-8100"`. Все найденные
проблемы возвращаются вместе.

## Состояния

| `State`            | Когда                                        |
|--------------------|----------------------------------------------|
| `StateOpen`        | соединение установлено (и сразу закрыто)     |
| `StateClosed`      | порт отверг подключение (`ECONNREFUSED`)     |
| `StateTimeout`     | не уложились в `WithConnectTimeout`          |
| `StateUnreachable` | нет маршрута до сети или хоста               |
| `StateCanceled`    | скан отменён через `ctx`                     |
| `StateError`       | всё остальное, в том числе неразрешённое имя |
| `StateUnknown`     | нулевое значение, проверка его не возвращает |

Нулевое значение намеренно не `StateOpen`: забытое поле не превратится в
«порт открыт».

Ошибка определяется через `errors.Is`, `errors.As` и `net.Error.Timeout()`,
текст ошибки не разбирается. Для Windows коды `WSAECONNREFUSED` и остальные
перечислены отдельно (`classify.go`), потому что они не равны `syscall.ECONNREFUSED`.

Отмену от таймаута отличает контекст всего скана: если `ctx` отменён, это
`StateCanceled`, если истекло только время попытки, `StateTimeout`. Если ответ
(отказ или недоступность) уже пришёл, поздняя отмена его не меняет.

## Параллельность и отмена

- **Лимит подключений общий для `Scanner`.** Два одновременных `Scan` на одном
  сканере вместе не превысят `WithConcurrency`. Слот занят только на время
  подключения, а не пока результат ждёт читателя.
- **Большие входы не копятся в памяти.** Задачи (адрес × порт) выдаются лениво,
  список всех пар не строится. Буфер канала результатов не больше 256.
- **Медленный читатель** замедляет скан, но память не растёт: воркеры ждут, пока
  результат заберут.
- **Отмена.** После отмены `ctx` новые проверки не начинаются, начатые
  прерываются (`StateCanceled`), канал закрывается. Результат, который уже некому
  принять, отбрасывается.
- **Канал закрывает сам пакет**, когда все воркеры вышли. Если после закрытия
  `ctx.Err() != nil`, результаты могут быть неполными.
- **Канал нужно дочитать или отменить `ctx`.** Иначе горутины скана останутся
  ждать читателя.
- **Порядок результатов не гарантируется**, кроме того, что неразрешённые хосты
  идут первыми. Порты раздаются по кругу между хостами, чтобы не бить в один
  хост подряд.
- Каждое соединение закрывается сразу после проверки. Время в `Result.Duration`
  это только время подключения.

## Подмена сети

`WithDialer` и `WithResolver` принимают интерфейсы, поэтому пакет проверяется без
настоящей сети: в тестах используется `testing/synctest` с фальшивым временем,
и тесты с задержками по секундам выполняются мгновенно. Таймаут в свой `Dialer`
класть не нужно, он приходит через контекст.

## Ограничения

- Только TCP connect. Фаервол, который молча отбрасывает пакеты, виден как
  `StateTimeout`, а не «закрыт».
- Каждое подключение занимает файловый дескриптор. На macOS лимит по умолчанию
  256 (`ulimit -n`), с большим `WithConcurrency` его нужно поднять.
- CIDR не поддерживается.
- Plan 9 не поддерживается (нет `syscall.Errno`).
